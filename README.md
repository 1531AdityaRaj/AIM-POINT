## 📖 About The Institute

**AIM POINT STUDY CIRCLE** is a premier educational institution located in Ashok Nagar, Chhota Govindpur, Jamshedpur. Founded in **1993**, the institute has guided over **5,000+ students** and produced numerous State, City, and School board rank holders across **CBSE, ICSE, and JAC boards**, as well as Senior Secondary Science streams (Physics, Chemistry, Maths, Biology).

---

## ✨ Features & Highlights

- 🎨 **Modern Responsive Design System**: Ultra-clean glassmorphism UI, fluid typography (Plus Jakarta Sans & Inter), and rich animations.
- 📱 **Mobile-First Experience**: Responsive sticky navbar with sliding drawer navigation.
- 📚 **Curricula & Courses**: Filterable course catalog covering Junior Foundation, Secondary Board Prep, and XI-XII Science.
- 🏆 **Hall of Fame / Achievers**: Filterable board toppers showcase with scorecards and medals.
- 📝 **Interactive Admission Form**: 4-stage online application form with **live passport photo preview**, client-side validation, and instant feedback.
- 📍 **Campus Location & Directions**: Interactive Google Maps embed and nearby landmark distance guides.
- 💬 **Direct WhatsApp & Phone Quick Connect**: Click-to-call and quick WhatsApp messaging buttons.

## 🚀 Getting Started

### 1. Run Frontend Locally
Simply open `index.html` in any modern web browser or serve via Live Server:
```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```

### 2. Run Backend Server (Optional)
```bash
cd backend
npm install
node server.js
```
*Backend runs on `http://localhost:5000`.*
